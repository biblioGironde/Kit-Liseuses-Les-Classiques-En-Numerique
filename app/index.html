Ouvrez cette page avec Chrome ou Edge

Pour copier des livres sur une liseuse, cette page a besoin de Google Chrome ou de Microsoft Edge, sur un ordinateur (Mac ou Windows). Firefox, Safari, les tablettes et les téléphones ne le permettent pas.

Vous êtes sur la liseuse elle-même ? Ouvrez la version pour liseuse pour télécharger les livres un par un.
